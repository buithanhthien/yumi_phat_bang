# Yumi ROS 2 workspace

ROS 2 Jazzy workspace. Source code is under `src/`; `build/`, `install/` and
`log/` are generated by colcon.

```text
src/
  yumi_phat_bang/    Yumi CAD, Gazebo simulation, SLAM simulation, WASD teleop
  yumi_robot_pkg/    Yumi hardware bringup, STM32 odometry, Ethernet LiDARs
  legacy_zackon_view_robot/  archived Zackon model and mapping configuration
  sllidar_ros2/      Slamtec LiDAR driver
  uros/              micro-ROS Agent, Jazzy-linked XRCE library, message sources
  micro_ros_setup/   micro-ROS tooling (not needed for basic bringup)
  tf2_frame/        source from Zackon
```

Build the packages needed for simulation and hardware bringup:

```bash
source /opt/ros/jazzy/setup.bash
cd /home/khoaiuh/yumi_phat_bang
colcon --log-base log build --base-paths src \
  --build-base build --install-base install \
  --packages-up-to yumi_phat_bang yumi_robot_pkg --symlink-install \
  --parallel-workers 2 --cmake-args -DBUILD_TESTING=OFF \
  -DCMAKE_BUILD_TYPE=Release -DUAGENT_SUPERBUILD=OFF \
  -DUAGENT_USE_SYSTEM_FASTCDR=ON -DUAGENT_USE_SYSTEM_FASTDDS=ON \
  -DUAGENT_USE_SYSTEM_LOGGER=ON -DUAGENT_BUILD_EXECUTABLE=OFF
source install/setup.bash
```

- Simulation: `ros2 launch yumi_phat_bang mapping_sim.launch.py`
- Hardware connection only: `ros2 launch yumi_robot_pkg yumi_hardware.launch.py`
- Hardware SLAM: `ros2 launch yumi_robot_pkg MAP_GENERATING.launch.py`

See [simulation instructions](src/yumi_phat_bang/docs/MAPPING.md) and
[hardware bringup instructions](src/yumi_robot_pkg/README.md). Stop Gazebo before
starting the real robot launch in the same ROS domain.

The hardware package is `yumi_robot_pkg`. Use a fresh terminal and source
`install/setup.bash`; do not source the older Zackon workspace.

## Selecting Yumi in a terminal

This machine's `.bashrc` automatically sources `zackon_build_up`. To clear that
inherited environment and select only ROS Jazzy plus this Yumi build, use:

```bash
source /home/khoaiuh/yumi_phat_bang/setup_yumi.bash
export ROS_DOMAIN_ID=0
ros2 pkg prefix yumi_robot_pkg
ros2 launch yumi_robot_pkg MAP_GENERATING.launch.py
```

Stop previous robot launches first; changing a package name does not stop existing
nodes using `/tf`, `/joint_states` or `/robot_description`. The setup helper resets
ROS/Python/CMake library search paths in the current shell, without editing `.bashrc`.
